# Getting started

From zero to your first green run in about five minutes.

<StepBlock step={1} title="Install the engine">

<StepDescription>Build the `tuilab` binary from the Rust workspace. You need Rust stable 1.75+.</StepDescription>

```bash
git clone https://github.com/soubhagya2001/TUI-Lab.git
cd TUI-Lab/tuilab
cargo build --release -p tui-lab-cli
./target/release/tuilab --help
```

<Callout title="Windows note" tone="warning">TUI Lab drives apps through Windows ConPTY on Windows and Unix PTYs elsewhere. Always verify on both — ConPTY parity is the project's top risk area (see CI &amp; troubleshooting).</Callout>

</StepBlock>

<StepBlock step={2} title="Scaffold a project" tag="tuilab init">

<StepDescription>Create `tuilab.yaml` plus a starter smoke suite.</StepDescription>

```bash
tuilab init
# -> tuilab.yaml + tests/smoke.yaml
```

```yaml
version: "1.0"
tests_dir: tests
snapshots_dir: tests/snapshots
default_terminal: { width: 120, height: 40 }
default_timeout: 10s
report: { json: reports/results.json, html: reports/index.html, junit: reports/junit.xml }
env:
  TERM: xterm-256color
```

</StepBlock>

<StepBlock step={3} title="Run your first suite" tag="tuilab run">

<StepDescription>Point a suite at any terminal app — this one drives the bundled Ratatui sample.</StepDescription>

```bash
tuilab run tests/e2e
```

```text
✓ smoke
✓ search-flow
2 passed, 0 failed
```

Depending on the exit code you know what happened: `0` all passed, `1` a test failed, `2` config/schema error, `3` launch/PTY error, `4` timeout with the hung process killed.

</StepBlock>

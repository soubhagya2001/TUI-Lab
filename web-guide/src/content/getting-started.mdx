# Getting started

From zero to your first green run in about five minutes. No Rust toolchain needed — just install and go.

<StepBlock step={1} title="Download and install">

<StepDescription>Pick the installer that fits your machine. Every option bundles the engine (`tuilab` + `tuilab-mcp`) — nothing else to download.</StepDescription>

<CodeTabs tabs={[
  {
    label: 'Windows', value: 'windows', content:
    <pre><code>{`pip install tui-lab
tuilab --version`}</code></pre>,
  },
  {
    label: 'macOS / Linux', value: 'unix', content:
    <pre><code>{`pip install tui-lab
tuilab --version`}</code></pre>,
  },
  {
    label: 'Node.js', value: 'node', content:
    <pre><code>{`npx @tui-lab/cli --version`}</code></pre>,
  },
  {
    label: 'Rust', value: 'rust', content:
    <pre><code>{`cargo install tui-lab-cli tui-lab-mcp
tuilab --version`}</code></pre>,
  },
  {
    label: 'Portable archive', value: 'archive', content:
    <pre><code>{`# Download the archive for your OS from GitHub Releases,
# unzip it, and add the folder to your PATH.
tuilab --version`}</code></pre>,
  },
]} />

<Callout title="Prefer uv?">`uv add tui-lab` works the same as pip, and `uvx tui-lab run …` runs without installing anything.</Callout>

</StepBlock>

<StepBlock step={2} title="Scaffold a project" tag="tuilab init">

<StepDescription>Create `tuilab.yaml` plus a starter smoke suite.</StepDescription>

```bash
tuilab init
# -> tuilab.yaml + tests/smoke.yaml
```

<Example title="Generated tuilab.yaml" description="Project settings created by init — edit paths, terminal size, and timeouts to taste.">

```yaml
version: "1.0"
tests_dir: tests
snapshots_dir: tests/snapshots
default_terminal: { width: 120, height: 40 }
default_timeout: 10s
report: { json: reports/results.json, html: reports/index.html, junit: reports/junit.xml }
env:
  TERM: xterm-256color
```

</Example>

</StepBlock>

<StepBlock step={3} title="Run your first suite" tag="tuilab run">

<StepDescription>Run the starter suite. A green run looks like this:</StepDescription>

```bash
tuilab run tests
```

<OutputBlock title="expected output">

✓ smoke
2 passed, 0 failed

</OutputBlock>

Each run ends with an exit code: `0` all passed, `1` a test failed, `2` config/schema error, `3` launch/PTY error, `4` timeout with the hung process killed.

</StepBlock>

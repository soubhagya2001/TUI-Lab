# Assertions & snapshots

Assertions are how a suite says "this screen is correct". TUI Lab checks
text, screen regions, cursor position, timing, and process health — plus
full-screen golden snapshots with masking for volatile content. Everything
below polls with timeout + retry, so assertions wait for the app instead of
racing it.

Every assertion below is a YAML fragment you can drop into a suite's `steps` or `assertions`. Each carries a timeout with polling + retry.

## Assertion snippets

Text — does the screen show it?

<Snippet label="yaml" code={`- assert_text:
    contains: "Dashboard"
- assert:
    text_visible: "Dashboard"`} />

Screen behavior — did the screen change, and did the app start fast?

<Snippet label="yaml" code={`- expect:
    screen_changed: true
- expect:
    startup_time_less_than: 2s`} />

Regions — scope a check to part of the screen:

<Snippet label="yaml" code={`- assert_region:
    x: 0
    y: 0
    width: 80
    height: 5
    contains: "CodeGraph"`} />

Cursor and process — where is the cursor, and did the app exit cleanly?

<Snippet label="yaml" code={`assertions:
  - cursor_position:
      row: 3
      col: 10
- assert_exit_code: 0
- assert_process_not_crashed: true`} />

## Snapshots (two kinds)

- **Golden snapshots** — full-screen text compared against a stored file. First run writes the golden; later runs diff.
- **Masked snapshots** — volatile regions (timestamps, CPU/RAM, IDs) declared with `region:` masks so goldens stay deterministic. Two layers, applied in order: `region:` entries (`region:rect:X,Y,W,H`, `region:top:N`, `region:bottom:N`) blank rectangles first, then `regex:` entries replace volatile spans.

<Example title="Suite with a masked snapshot" description="The clock and status line change every run, so a regex plus a bottom-row mask blanks them — everything else must match exactly.">

<Snippet label="tests/dashboard.yaml" code={`schema: tui-lab/v1
name: Dashboard snapshot
application:
  command: "./myapp"
terminal:
  width: 120
  height: 40
steps:
  - wait_for_text: "Dashboard"
  - snapshot:
      name: dashboard
      mask:
        - regex: "\\\\d{2}:\\\\d{2}:\\\\d{2}"
        - region:bottom:1
cleanup:
  - press: q`} />

</Example>

<Callout title="Mask everything volatile">Time, PIDs, durations, and random IDs must be maskable. An unmasked golden is a flaky test waiting to happen.</Callout>

## Timing / retry semantics

Every wait and assertion carries a timeout with polling + retry. Tune per step with `timeout:` — generous on launch and first paint, tight on steady-state interactions.

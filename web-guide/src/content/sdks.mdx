# SDKs

One rule: **SDKs are thin wrappers**. No native PTY code — each SDK spawns the `tuilab` binary and speaks the `tuilab proto` JSON-lines wire contract (one action in, one reply out). Priority order: Python first, then JavaScript, then Rust. Versions move in lockstep with the engine.

    t.assert_text(contains="Dashboard")`}</code></pre>,

await t.waitForText("Main Menu", { timeout: 5000 });
await t.press("ENTER");
await t.waitForText("Dashboard");
await t.assertText({ contains: "Dashboard" });`}</code></pre>,
  },
  {
    label: 'Rust', value: 'rust', content:
    <pre><code>{`use tui_lab_sdk::TuiTest;

let t = TuiTest::launch("./myapp").await?;
t.wait_for_text("Main Menu", Duration::from_secs(5)).await?;
t.press("ENTER").await?;
t.wait_for_text("Dashboard", Duration::from_secs(5)).await?;
t.assert_text_contains("Dashboard").await?;`}</code></pre>,

<Callout title="Binary resolution">Each SDK locates the `tuilab` binary (PATH, then well-known build locations) and surfaces a clear error when it is missing — install the engine first (see Getting started).</Callout>

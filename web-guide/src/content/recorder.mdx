# Recorder

`tuilab record` is the Playwright-Codegen equivalent: drive the app, get YAML with smart waits synthesized for you.

## Recording a flow

```bash
tuilab record -- myapp --flag
# drive the app with your keyboard...
# end with Ctrl+\ or stdin EOF — quit the app first (q)
```

The recorder owns the PTY, paces input in beats, forwards bytes verbatim, and emits a suite where pauses become `wait_for_text` steps with border-stripped targets — never `sleep`.

<Example title="Emitted recording" description="What the recorder writes: your keypresses interleaved with the waits it synthesized. Hand-tune from here.">

```yaml
schema: tui-lab/v1
name: recorded-login
application:
  command: "./myapp"
steps:
  - wait_for_text: "Login"
  - type: "demo"
  - press: TAB
  - type: "s3cret"
    sensitive: true
  - press: ENTER
  - wait_for_text: "Dashboard"
cleanup:
  - press: q
```

</Example>

## Replay the capture

```bash
tuilab run tests/recorded-login.yaml
```

Recorded YAML is ordinary `tui-lab/v1`: edit it, add `assert_text` and masks, commit it like a hand-written suite.

<Callout title="Quit first">Always quit the app before ending the recording. The trailing shutdown sequence otherwise lands in your suite as mystery steps.</Callout>

# MCP & AI agents

`tuilab-mcp` plugs the engine into any AI assistant that speaks the Model Context Protocol. Your agent launches terminal apps, presses keys, reads screens, and runs whole suites — while you watch.

<StepBlock step={1} title="Install the engine">

<StepDescription>The MCP server ships with every installer — `pip install tui-lab` or `npx @tui-lab/cli` both put `tuilab-mcp` on PATH. Verify:</StepDescription>

```bash
tuilab-mcp --help
```

</StepBlock>

<StepBlock step={2} title="Connect your assistant" tag="one-time setup">

<StepDescription>Register `tuilab-mcp` as a stdio MCP server. Pick your tab:</StepDescription>

<CodeTabs tabs={[
  {
    label: 'Claude Code', value: 'claude', content:
    <pre><code>{`claude mcp add tuilab -- tuilab-mcp`}</code></pre>,
  },
  {
    label: 'Cursor', value: 'cursor', content:
    <pre><code>{`// .cursor/mcp.json
{
  "mcpServers": {
    "tuilab": { "command": "tuilab-mcp" }
  }
}`}</code></pre>,
  },
  {
    label: 'VS Code', value: 'vscode', content:
    <pre><code>{`// .vscode/mcp.json
{
  "servers": {
    "tuilab": { "command": "tuilab-mcp" }
  }
}`}</code></pre>,
  },
  {
    label: 'Windsurf', value: 'windsurf', content:
    <pre><code>{`// ~/.codeium/windsurf/mcp_config.json
{
  "mcpServers": {
    "tuilab": { "command": "tuilab-mcp" }
  }
}`}</code></pre>,
  },
  {
    label: 'Any MCP client', value: 'generic', content:
    <pre><code>{`{
  "mcpServers": {
    "tuilab": {
      "command": "/absolute/path/to/tuilab-mcp"
    }
  }
}`}</code></pre>,
  },
]} />

<Callout title="Not on PATH?">If your assistant can't find the server, use the absolute path (last tab). Find it with `which tuilab-mcp` on macOS/Linux or `where tuilab-mcp` on Windows.</Callout>

</StepBlock>

<StepBlock step={3} title="Ask your agent to test" tag="first session">

<StepDescription>Try a prompt like this and watch the agent drive your app:</StepDescription>

<Example title="First agent-driven test" description="Paste into your assistant after connecting the server.">

```text
Launch ./myapp with TUI Lab, wait for the main menu,
select the second item, and tell me what the screen shows.
Then close the session.
```

</Example>

The agent will launch a session, synchronize on screen text (never fixed sleeps), report what it sees, and close up — or run a whole `tests/` suite file and triage the failures for you.

</StepBlock>

<Callout title="Safety rails">The server only runs commands listed in `security.allow_commands` in `tuilab.yaml`, and only inside your project folder. Passwords typed with the sensitive flag never reach logs. Sessions are capped at 8 concurrent with a 60s idle kill.</Callout>
